# Verificación y Validación — Proyecto GameHub
## Características mínimas
**1.** El catálogo avanzado de videojuegos y consolas con filtros por género, plataforma y ESRB.

**2.** El sistema de recomendaciones basandose en el historial de compras y preferencias del usuario.

**3.** La gestión de preventas con notificaciones automáticas al usuario.

**4.** El carrito de compras con integración de pagos (Stripe/PayPal).

**5.** Comunidad integrada: perfiles de usuario, reseñas, listas de deseos.

**6.** Un panel administrativo completo para gestión de productos, categorías, inventario, pedidos y usuarios.
